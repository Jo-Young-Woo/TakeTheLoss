# 수광 돔 노출 자세: 심판 기하 시험

실제 ArenaReferee._first_receiver와 생성된 WINGBOT 프레임으로 장애물이 없는 별도 시험을 수행했다. 로봇 차체 가림과 좌·우 돔의 반구 수광 조건은 그대로 유지했다. 발사자와 표적의 높이는 동일하며 표적만 정면·후면·좌측·우측으로 돌렸다. 각 거리·방향마다 같은 팬·틸트 격자 1,271개 광선을 평가했다.

| 거리 | 정면 교차 | 후면 교차 | 좌측 교차 | 우측 교차 |
|---|---:|---:|---:|---:|
| 0.6m | 0/1271 | 0/1271 | 65/1271 | 65/1271 |
| 1.0m | 0/1271 | 0/1271 | 41/1271 | 41/1271 |
| 1.5m | 0/1271 | 0/1271 | 32/1271 | 32/1271 |

이 모델에서는 정확히 정면·후면을 향하면 옆 돔 노출이 줄어드는 가설을 지지한다. 위 값은 정해진 각도 범위의 광선 교차 횟수이며, 2초 연속 조준을 요구하는 실제 유효피격 확률이 아니다. 움직임, 추적 오차, 경로 지연, 조명, 실물 반사와 보정을 측정하지 않았다.

방향 비용은 적용하지 않았다. 임무 수행 A/B에서 피격 감소와 M2·M3·M5 손실 여부를 확인한 뒤에만 채택한다. 실물 수광 돔 형상·방향과 레이저 광축은 여전히 실측 검증이 필요하다.

재현: python scripts/study_receiver_exposure.py

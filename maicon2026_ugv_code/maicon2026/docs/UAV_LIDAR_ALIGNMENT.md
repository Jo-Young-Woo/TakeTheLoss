# UAV–LiDAR 지도와 외곽면 기록

2026-11-12 수정. 기존 사용자 변경을 유지하고 현재 개발 런타임에 적용했다.

## 확인된 문제

- `CoverageMap`의 UAV 장애물은 관측 지점 선정에는 들어갔지만, 기본 A*와 위험 회피 경로의 비용 지도에는 빠졌다. 같은 목표를 두고 서로 다른 장애물 지도를 사용했다.
- UAV–LiDAR 등록은 평행이동이며 로봇 방향 오차를 보정하지 않는다. 국소 SLAM 지도에만 영상을 맞추면 SLAM 자체가 틀어진 경우를 해결할 수 없다.
- 종전 LiDAR 안전 제한은 전방/후방 부채꼴 위주였다. 제자리 회전으로 차체 모서리가 측면 벽에 닿는 상황을 별도로 검사하지 않았다.
- UAV에서 내부 면으로 분류한 인덱스가 영구 누적됐다. 이웃 가설이 사라져도 다시 외곽면으로 복구되지 않았다. 벽 인접 판정도 국소 보정 좌표와 경기장 좌표를 혼용했다.

기존 3대3 기록 `results/gazebo_selfplay_iff_labels_fixed_20261112`의 시간별 추정/평가 좌표를 비교하면, R2 위치 오차 최대 1.064m, 방향 차이 최대 36.77°였다. 이는 지도 간 등록 잔차가 아니라 기록된 로봇 추정 자세와 평가용 실제 자세의 차이다. 평가 시간 오차(최대 0.25초 허용), 센서 전달 지연과 회전 중 오차도 포함하므로 센서 동기화된 정밀 측정값으로 해석하면 안 된다. 실제 자세는 분석에만 쓰며 Agent에 전달하지 않는다.

## 적용한 변경

1. `OccupancyGrid.planning_prior`에 영상 장애물을 별도 저장한다. 기본 A*, 위험 회피, 차체 경로 검사, 새 장애물 재계획이 같은 계획 점유 지도를 사용한다. `grid.L`, LiDAR 장애물 추출, SLAM의 국소 지도에는 영상 가설을 쓰지 않는다. 반복된 자유공간 관측(로그오즈 ≤ -1.35)으로 영상 가설을 반박할 수 있다.
2. 현재 Gazebo의 내장 위치 추정기는 확인된 UAV 장애물 3개 이상을 추가 기준으로 쓴다. 원본 경기장 좌표의 사각형 표면에 LiDAR 끝점을 비교하여 x/y/방향 입자 가중치를 보정한다. 국소 좌표로 옮긴 가설을 다시 절대 기준으로 쓰지 않는다. UAV가 끊기면 만료시키고, 사용자가 고정하도록 설정한 첫 지도는 유지한다. 기본 오도메트리·벽·LiDAR 지도 추정은 계속 작동한다. 이 변경은 외부 Nav2 위치 추정기를 대체하지 않는다.
3. LiDAR 차체 좌표에서 앞으로 이동할 직사각형의 모서리까지 검사한다. 전진·후진·제자리 회전, 반응 시간과 제동거리, 근접 상태에서 벽으로 더 들어가지 않는 탈출 동작을 처리한다. 명령 감속 처리 뒤에도 제한을 적용한다. 위치 추정/UAV 오차와 별개로 작동한다.
4. UAV 내부 면과 LiDAR 내부 면의 근거를 분리한다. 이웃 가설이 바뀌면 UAV 제외 상태를 재계산한다. 벽 판정은 경기장 좌표를 사용한다.
5. `face_ledger.json`의 `uav_map.outer_faces`에 박스/면 ID, 노출 선분의 양끝 좌표, 바깥 법선, 노출 비율, 벽 접근 불가 여부, 장부 상태, 영상 시각을 저장한다. 부분 가림은 남은 선분을 보존한다. 기존 M3의 부분 가림 제외 정책은 그대로 유지하므로 선분이 남았다는 이유만으로 점수를 부여하지 않는다. 영상 오른쪽 지도에는 실제 박스 크기와 외곽 선분을 표시한다.

## 좌표와 관측의 계약

- 경기장: 좌하단 (0,0), 우상단 (6,4.8)m. Gazebo world 원점은 중앙이므로 평가할 때만 (+3,+2.4)를 적용한다.
- LiDAR: 장착 변환은 `ros_mil.scan_in_base`에서 한 번만 적용한다. 차체 원점 기준 끝점으로 보수적으로 다시 나눈다. 이번 수정으로 센서 오프셋을 두 번 적용하지 않는다.
- UAV: 기존 다점 격자 보정과 독립 체크포인트 검증을 유지한다. 바닥과 0.4m 박스 윗면은 서로 다른 투영 평면이다. 바닥 보정만 박스 윗면에 쓰면 위치가 어긋날 수 있다.
- 외곽면 지도는 축에 평행한 사각형 장애물 가정이다. 임의 회전 물체/비정형 물체에는 그대로 일반화할 수 없다. 상공 영상에서 옆면 그림의 종류를 추정하지 않는다. M3 식별은 지상 카메라와 연결한다.

## 후속 개선과 검증 범위

실기에서는 영상 왜곡 보정 후 여러 격자 교점으로 보정하고, 보정에 쓰지 않은 점에서 오차를 측정한다. 촬영 시각의 자세/TF로 센서를 맞추고, 벽과 여러 분리된 구조물에서 회전까지 관측 가능한 경우에만 정합을 갱신한다. 반복 배치에서는 잘못된 대응점에 주의한다. 현재 평행이동 등록을 무조건 회전 정합으로 확대하지 않았다.

2D LiDAR 높이와 교차하지 않는 물체는 이 안전 검사에서도 보이지 않는다. 실기 Nav2에는 별도의 장애물 층 연결과 깊이/범퍼 센서 검증이 필요하다. 지도 계획과 별도로 센서 기반 최종 충돌 제한을 두는 방식은 [Nav2 Collision Monitor](https://docs.nav2.org/rolling/configuration_and_development/configuration_guide/core_servers/collision_monitor/configuring_collision_monitor_node/)의 접근과도 일치한다. 여기서는 설치된 Humble 환경에 새 Nav2 플러그인을 도입하지 않고 기존 공통 제한기를 보강했다.

시험·영상 및 수정 전후 비교는 `results/gazebo_map_alignment_20261112`에 기록한다. 90초의 6대 동시 시험이며 전체 경기 점수나 무충돌 보증 시험은 아니다.

# 차체 외곽(footprint) · LiDAR 오차 예산 · 경기장 유효성

> 시뮬 결과는 **실기 안전성의 증거가 아니다.** 시뮬은 2D 직사각형 외곽(높이·바퀴·안테나 돌출 없음)이고, LiDAR 오차 수치는 PDF 에 없어서 전부 **가정값**이다.

## 2. 외곽 기준과 여유거리 (`footprint.py`)
- **기준 외곽 = 방향이 있는 직사각형 250×230 mm.** 외접 반경 0.1698 m, 내접 반경(반폭) 0.115 m.
- 원이 필요한 곳은 용도별로 다른 반경을 쓴다(작은 원 하나로 때우지 않는다):
  - 직진 통과(A* 하드 인플레이션): 반폭 + 계획 여유 = **0.164 m**
  - 제자리 회전 소거: 외접 + 계획 여유 = **0.219 m** (그래서 40 cm 통로(반폭 0.20) 안 제자리 회전은 **불가**로 판정)
  - 경로 확정 전: 진행 방향으로 놓은 실제 직사각형(+계획 여유)과 꼭짓점 회전 원을 검사(`path_violations`)
- **LiDAR 불확실도 6종 분리**(`LidarErrCfg`, 전부 `assumed`, 출처 문자열 기록, PDF 에 정확도 수치 없음):

| 항목 | 값(가정) | 사용 계층 | 여유 환산 |
|---|---|---|---|
| 거리 편향 | 5 mm | 계획+정지 | +5.0 mm |
| 장착 위치 xy | 5 mm | 계획+정지 | +5.0 mm |
| 거리 잡음 σ 8 mm (k=2) | | 계획+정지 | RSS 에 포함 |
| 각도 오차 0.3° × 기준거리 0.5 m (k=2) | | 계획+정지 | RSS 에 포함 |
| 장착 yaw 0.5° × 0.5 m (k=2) | | 계획+정지 | RSS 에 포함 (잡음+각도+yaw RSS = 19.0 mm) |
| 전달 지연 0.10 s × 기준속도 0.38 m/s | | **정지만** | +38.0 mm |
| 자기 위치추정 σ 10 mm (k=2) | | **계획만** | +20.0 mm |
| 누락 2 %·이상치 0.5 % | | 거리 여유로 메우지 않음 | 지속성 필터(여러 스캔) |

  → `plan_margin` = 센서 항(29.0) + 위치추정(20.0) = **49 mm**, `stop_margin` = 센서 항(29.0) + 지연(38.0) = **67 mm**.
  **중복 가산 방지 근거**: 센서 항은 같은 측정을 쓰는 두 계층이 *각자 한 번*; 지연은 실시간 정지 판단에만(계획은 속도를 가정하지 않음); 위치추정 오차는 계획에만(안전 정지는 로봇 좌표계 LiDAR 상대 거리를 쓰므로 위치추정이 들어가지 않음). 제동거리는 여유가 아니라 감속 구간(`slow_dist`)이 맡는다. Nav2 는 footprint 를 `plan_margin` 만큼 키우고 `footprint_padding: 0.0`(기본 0.01 을 더하면 이중 가산), `inflation_radius` 는 비용 기울기용이다.
- 계층별 결과(전부 `Config.budget()` 한 곳에서 파생, `Config.consistency()` 가 불일치 검사):

| 계층 | 값 | 계산 |
|---|---|---|
| 시뮬 충돌 | 직사각형 250×230 (SAT, 벽·박스·다른 UGV) | PDF |
| 내장 A* 하드 인플레이션 `nav.inflate_hard` | 0.164 m | 0.115 + 0.049 |
| 회전 소거 `nav.rotate_clear` | 0.219 m | 0.1698 + 0.049 |
| LiDAR 정지 `nav.stop_dist` | 0.192 m | 0.125 + 0.067 |
| 측면 보정 `nav.side_lim` | 0.178 m | 0.115 + 0.067 |
| Nav2 footprint | ±0.174 × ±0.164 m | 0.125/0.115 + 0.049 |
- 40 cm 통로: 한쪽 여유 0.085 m, 계획 여유 후 0.036 m → **직진 통과 가능, 제자리 회전 불가**. 30 cm 틈은 불가(여유를 줄여 통과시키지 않음).

## 3. 경로계획 변경
- `nav/fpplan.py` (`plan_footprint`, 내장 항법과 경기장 검사가 **같은 함수**): ① 트인 칸에서만 대각 이동을 허용하는 A*(좁은 곳은 축 방향) ② 가시선 단순화(좁은 곳 비스듬한 지름길 금지) ③ 직사각형 검증 → 위반 시 (a) 좁은 틈 입구면 축 정렬 우회(트인 곳에서 정렬 → 직진 통과 → 통과 뒤 꺾기) (b) 꼭짓점 회전 공간이 없으면 직진 띠만 남기고 그 둘레를 막기.
- 인플레이션 **완화 루프 삭제**(`nav.relax_inflation=False`). 못 찾으면 `blocked` → 복구/정지.
- 복구 힌트·위협 회피 코드는 그대로.

## 4. 경기장 유효성 (`sim/arena_check.py`, `World._build_valid_layout`)
검사(하나라도 실패 → 그 배치 제외·재생성):
| 사유 | 의미 |
|---|---|
| `placement:` | 박스를 놓지 못한 구역(예전엔 조용히 건너뜀) |
| `spacing:` | 박스 사이 이격 < `arena.min_gap`(0.40 m, PDF p24) |
| `content:` | 양 진영에 필수 표적 3종이 각 1개씩, 객체 박스 ≥3개 |
| `start:` | 6개 출발 거점 자세에서 직사각형(+여유)이 박스·벽과 겹침 |
| `goal:` | 각 출발 → 상대 진영 **3개 목표거점 중심**까지 footprint 경로 없음 |
| `target:` | 각 출발에서 지정될 수 있는 표적 3종 각각의 접근·조준 자세(차체가 면을 향함, 사선 안 가려짐, 거리 0.65/0.85/1.1 m × 옆 0/±0.15 m)까지 주행 불가 |
- 중심점 A* 로는 통과 판정을 하지 않는다. 박스 래스터화는 칸 **중심**이 박스 안인 칸(기존 `add_static_box` 는 경계 칸까지 포함해 정확히 40 cm 틈을 막는다).
- 재생성: 시도 k 의 배치 시드 = `seed + 10007·k`(결정적, 같은 seed → 같은 결과), 상한 `arena.max_layout_tries`=30, 초과 시 `ArenaGenerationError`(사유 포함). 기록: `world.layout_meta = {seed, attempts, used_layout_seed, excluded:[{attempt, layout_seed, reasons}]}`.
- 정적 검사다: 경기 중 구조물 변경(`shuffle_structures`)은 다시 검사하지 않는다.

## 6. 현장에서 반드시 측정할 항목
1. **차체 실치수**: 길이·폭을 줄자로(바퀴 바깥, 안테나·카메라 마스트 돌출 포함 여부), 진행 방향이 250 mm 변인지. → `calib/robot_profile.yaml` 의 `model.size` 를 `measured` 로 고치면 `Config.apply_budget()`/`calib_gen` 이 파생값 전부를 다시 만든다.
2. **LiDAR 오차 6종**(`sensors.lidar.error.*`, 지금은 전부 assumed): 정지한 평면 벽 앞 0.3/1/2 m 에서 줄자 거리 대비 편향·잡음, 직각 모서리 방위 반복(각도 오차), 장착 위치·yaw(`calib:lidar_square`), 스캔 stamp 지연(F01), 정지 표적 N회 위치추정 오차.
3. **40 cm 통로 실주행**: 직진·비스듬한 진입·통로 안 회전 가능 여부, 정지 위치(차체 앞 끝과 벽 사이). 특히 **제자리 회전 시 실제 쓸리는 반경**(스키드 조향)이 0.17 m 인지 — 시뮬은 0.2 m 폭에서 회전 불가로 판정한다.
4. 박스 모서리·벽 근처에서 `collision ahead`(Nav2) 횟수: 직사각형 footprint 로 되돌렸으므로 예전처럼 자주 멈추는지(예전 WSL 400회/매치) 확인. 이번엔 1회 실행에서 0줄이었다.
5. 박스 실제 배치 간격(PDF p24 의 40 cm 이상이 실제 얼마인지)과 `arena.*` 좌표.

## 7. 알려진 한계
- 시뮬 충돌은 2D 직사각형(바퀴 돌출·마스트·안테나 없음). 높이(LiDAR 평면 아래·위 물체)는 별도 3D 지도 코드가 다룬다.
- 카메라/깊이 시뮬의 다른 UGV 형상은 아직 원기둥(`UGV_R`=0.13)이다(LiDAR 와 레이저 가림만 직사각형으로 바꿨다).
- 경로 검증은 "진행 방향 직사각형 + 꼭짓점 원"이라는 *근사*이며 곡률·제어 오차는 모른다. 좁은 틈은 '정렬 → 직진 → 꺾기'로 재구성한다. 이 때문에 경로가 우회·길어질 수 있다.
- 경기장 검사는 정적이다(경기 중 박스 재배치 후 재검사 없음). 무작위 생성기는 비효율적(첫 시도 25 %만 유효).
- LiDAR 오차 변형은 시드 3개·변형당 3경기라 표본이 매우 작다. 예산(5 mm 편향 등)을 크게 넘는 오차(−3 cm)는 덮지 못한다.

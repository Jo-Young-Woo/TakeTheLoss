## 아직 입증되지 않은 원인

가장 우선 확인할 가설은 **영상 촬영 시점과 현재 팬·틸트 사이의 차이를 보정하지 않은 반복 조정**이다. STRIKE는 비동기 검출 사이에 같은 검출 결과를 여러 제어 틱에서 재사용하며, 조준기는 `현재 팬 + 0.9 × 영상 오차`를 다시 적용한다. 지도 투영에는 촬영 시점의 자세가 들어가지만 이 조준 호출과 거리 추정에는 현재 팬 값이 쓰인다. 팬 이동과 차체 중앙 복귀가 겹치면 오래된 오차를 반복 적용하여 과잉 회전할 수 있다. 위 회전 반전과 초기화 횟수는 이 가설과 일치하지만, 원인으로 확정할 수는 없다.

수광부 누락·다른 원형 무늬 선택·면 매칭 변경·거리 추정 오차·고정 축 오차도 조준 중 영상이 없어 분리하지 못했다. 레이더 텍스처에는 상단 중앙의 흰 원판이 실제로 있고, 대체 조준 위치와 가깝다. 다만 텍스처 확인만으로 움직이는 로봇의 영상에서 원판이 계속 검출됐다고 주장할 수 없다.

저장된 시뮬레이션 보정 자료는 레이저의 카메라 대비 수직 위치 46.5mm와 일치하고, Ogre2에서 지원하지 않은 왜곡의 유효 계수는 0으로 기록돼 있다. 현재 증거만으로 외부 보정값이나 왜곡값을 바꾸는 것은 타당하지 않다. 실제 하드웨어 보정이 검증된 것은 아니다.

## 다음 실제 시험의 조준 증거

`scripts/aim_diagnostics.py`는 실제 `AimController.update` 호출의 입력과 반환값을 그대로 기록한다. 촬영 시각·촬영 당시 자세와 팬틸트, 현재 자세와 팬틸트, 수광부 후보 픽셀, 필터 후 겨냥점, 각도 오차, 정렬 유지 시간, 같은 검출 재사용 횟수를 남긴다. 발사 검사 함수는 원래 실행된 경우에만 결과를 기록한다. 앞선 조건에서 중단되어 호출되지 않은 검사를 통과 또는 실패로 추측하지 않는다.

카메라 원본은 검출이 사용한 촬영 식별자와 정확히 일치할 때만 연결한다. 최신 화면을 오래된 검출의 근거로 대체하지 않으며, 일치하는 프레임을 보관하지 못한 경우에는 없다고 표시한다. 이 도구는 조준 명령·허용 오차·발사 조건을 바꾸지 않는다. 기록 설치 전후의 조준 출력 동일성과 검사 함수 호출 수 보존, 프레임 식별·복사 보존을 시험했다. 실제 경기에서의 반복 오차 적분 가설은 이 계측으로 확인해야 하며 아직 입증한 것으로 표시하지 않는다.

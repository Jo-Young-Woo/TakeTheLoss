# LiDAR 새 트랙의 이전 자유공간 검증

candidate04는 `progress.enabled=True`인 빠른 검출 경로에서만 새 트랙의 출생 조건을 보강한다. 기존 모드(`progress.enabled=False`)는 이전 검출 경로를 그대로 사용한다. 검사 기능을 끄는 설정은 수치 비교용이며 현재 후보 기본값은 켜짐이다.

표면의 `free_seen` 이력만으로 새 트랙을 만들지 않는다. 이전 LiDAR 광선이 끝점보다 충분히 앞쪽에서 통과한 셀을 따로 저장하고, 추정 차체 중심과 내부 주변이 그 자유공간에 포함되는지 확인한다. 현재 스캔은 자기 출생의 근거가 될 수 없도록 검출 이후에만 이력을 갱신한다. 카메라 정답이나 경기장 실제 구조물 좌표를 읽지 않는다.

| ThreatCfg 키 | 기본값 | 의미 |
|---|---:|---|
| lidar_birth_require_prior_interior | True | 후보 경로의 새 출생 검사 사용 |
| lidar_birth_guard_m | 0.12m | 반사 끝점 앞에서 자유 근거를 멈추는 거리 |
| lidar_birth_support_radius_m | 0.05m | 추정 중심 주변 검사 반경; 기본 격자에서 3×3셀 |
| lidar_birth_min_free_fraction | 0.75 | 지지 비율; 중심 셀 필수이며 기본 격자에서는 9개 중 7개 이상 |

이 수치는 위치·거리 잡음에 대한 가정값이며 실제 장비에서 측정된 허용 오차가 아니다. 큰 위치 추정 점프와 큰 회전 오차를 보장하지 않는다. 자유공간 이력이 오래 유지되므로 장기간 지도의 일관성도 별도 검증해야 한다. 이미 검증된 트랙의 연관·Kalman 갱신은 그대로 유지하여 멈춘 실제 UGV를 정적 물체로 흡수하지 않는다. 기존 트랙에 잘못된 인접 반사가 연관되는 문제는 별도 남아 있다.

처음 보는 공간에 정지한 작은 물체는 LiDAR만으로 박스와 UGV를 구분할 수 없다. 이때 UGV 위협으로 바로 승격하지 않지만 점유 지도와 충돌 회피에는 계속 장애물로 남는다. 이동하여 관측된 자유공간에 들어오거나 카메라/UAV가 확인하는 경로가 필요하다.

## 진단과 검증

`agent.blobs.stats`에서 `birth_support_checks`, `birth_accepted`, `birth_rejected_no_prior_interior`, `guarded_free_cells`를 읽을 수 있다. 앞의 세 항목은 누적 횟수이고 마지막 항목은 현재 저장한 자유 지지 셀 수다. 지원되지 않은 출생을 버려도 실제 LiDAR 점유를 지우지 않는다.

고정 0.4×0.4m 박스에 위치 흔들림(+8cm, −4cm, 이후 ±2.5cm)과 3mm 빔 잡음을 넣은 반례에서 이전 조건은 40개 스캔 중 39개에 허상 1개를 만들었다. 새 조건은 0개였다. 인접한 긴 구조물이 있는 경우도 같다. 기존 정지 blocker 유지, 움직이는 UGV의 속도·만료, 확인된 박스 옆 실제 UGV, 긴 벽 위치 흔들림 시험은 수정 없이 통과했다. 처음 보는 정지 물체·무효 광선·초기화·기존 모드 분리 시험도 추가했다. Windows와 WSL에서 관련 시험 32개가 통과했다.

WSL의 640점·5개 UGV 합성 입력 120회에서 검출 p95는 새 조건을 끈 경우 0.96ms, 켠 경우 3.18ms였다. 이전 광선 자유공간 이력 계산을 포함한 값이다. 별도의 100회 전체 경로 측정에서는 LiDAR 계산 p95 3.41ms, 위험장 발행까지 p95 8.63ms였다. 이는 단독 합성 CPU 시험이며 여섯 Agent 실제 Gazebo 부하나 Jetson 성능을 뜻하지 않는다. 실제 실험의 허상 수와 지연은 다음 실행에서 다시 확인해야 한다.

검증 자료: `recordings/candidate04_lidar_20261109/detector_comparison.json`, `recordings/candidate04_lidar_20261109/latency.json`. 공식 회귀 시험은 `tests/test_lidar_birth_support.py`이고 기존 시험은 변경하지 않았다. tmp 프로토타입은 역사적 실험 자료이며 production 검증은 공식 시험을 사용한다.

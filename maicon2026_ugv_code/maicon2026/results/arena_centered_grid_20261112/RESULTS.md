# 중앙 방향 20cm 격자 정렬

2026-11-12. 사용자의 요청에 따라 장애물 9묶음 중 8묶음(20개 중 18개 박스)을 중앙 쪽으로 옮겼다. 이미 정중앙인 2개는 유지했다.

- BLUE/RED의 좌우 묶음: x 방향으로 중앙 쪽 20cm.
- 위쪽/아래쪽 묶음: y 방향으로 중앙 쪽 20cm. 모서리 묶음은 두 축으로 이동하므로 총 이동 거리는 약 28.3cm다.
- CM 위·아래 단독 박스: y=±1.2m에서 ±1.0m.
- 좌표는 원본 인쇄의 20cm 격자(world 중심 원점)에 맞췄다. 확장 경기장의 항법 원점과 격자 시작점은 다르므로 항법 x/y를 단순히 0.2의 배수로 반올림하지 않았다.
- 묶음 형태·좌우 대칭·40cm 박스 크기·섹터·표적/M3 면 배정은 유지했다. 거점 센서와 고정 설비도 유지했다.

최소 묶음 간격 0.40m, 장애물-내벽 간격 0.70m, 장애물-고정 설비 간격 0.63m. 실제 WINGBOT 외곽 크기로 평면 접근 검사를 통과했다. 이 검사는 경기 중 모든 M3 그림 식별을 보장하지 않는다.

Gazebo 생성 세계와 WSL 설치본을 갱신했다. 실제 B-2 한 대를 대기 상태로 띄워 센서 수신과 UAV 화면을 확인했으며 경기는 시작하지 않았다. UAV 영상에서 박스 후보 20개, 배치 박스와 중복 없이 대응한 수 20개를 확인했다. 이는 상공 형상 확인이며 옆면 그림 식별 결과가 아니다.

관련 회귀 검사: **70 passed in 10.14s**. 정적 세계 검사 오류 0개, 시각 요소 57개·충돌체 28개로 유지.

# 후보 02: 6대 자가 대전 2회 + B-2 단독 2회

2026-11-09. 사용자가 5회씩에서 **각각 2회**로 범위를 변경했다. 모두 Gazebo 실제 모델·센서를 사용했고, 시드 0과 1로 실행했다. 선택된 후보 02 동결 패키지를 사용하며, M3는 기존 `scripts/evaluate_wingbot_missions.py`로 마지막 접수 스냅샷을 경기장 배치와 대조했다. 로컬 배점 집계는 [기계 판독 결과](score_summary.json)에 있다. 공식 경기 서버 확정 점수는 아니다.

| 방식·시드 | 경기 종료 시각 | M2+M3 | B-2 M3 | 점수 |
|---|---:|---:|---:|---:|
| 6대 자가 대전 0 | 252.252초, BLUE R-2 점령 | 14점(6대 합계) | 0점 | BLUE **157** / RED **82** |
| 6대 자가 대전 1 | 250.952초, BLUE R-2 점령 | 28점(6대 합계) | 7점 | BLUE **159** / RED **89** |
| B-2 단독 0 | 254.7초, BLUE R-2 점령 | 7점 | 7점 | **42점**(채점 가능한 M1~M5 소계) |
| B-2 단독 1 | 254.904초, BLUE R-2 점령 | 0점 | 0점 | **35점**(채점 가능한 M1~M5 소계) |

6대 경기의 점수는 M1 10점씩, M2 0점, M4 15점씩, BLUE 거점 점령에 따른 M5 10점씩, 연합 승리 보너스 5점씩을 포함한다. M3는 정확히 일치한 구역만 7점이다. 6대 경기 시드 0에서는 B-3의 `R-S2`와 R-1의 `B-S2`, 시드 1에서는 B-2의 `R-S3`, B-3의 `R-S2`, R-1·R-3의 `B-S2`가 맞았다. 공통 CM은 두 판 모두 전원 불일치했다. M2 유효 명중과 UGV 피격은 네 판 모두 0건이다.

**M6는 동점인 상대를 ID 순으로 정렬하는 로컬 채점기의 잠정 규칙**을 적용했다. 6대 경기에서 BLUE의 M6 점수는 시드 0에서 B-1/B-2/B-3 = 15/15/0, 시드 1에서 10/5/10이다. RED의 M6는 두 판 모두 전원 0이다. 실제 대회 서버의 동점 처리에 따라 6대 경기의 총점이 달라질 수 있다. 단독 경기에는 물리적 상대 3대가 없으므로 M6와 연합 승리 보너스를 채점하지 않았다. 단독 경기의 42/35점은 6대 경기의 개인 총점과 직접 비교할 수 없다.

단독 B-2의 M3 신고는 시드 0에서 정답 21개 중 18개, 시드 1에서 21개를 신고했다. 그러나 시드 1은 구역·종류별 개수가 모두 맞은 구역이 없어 **M3 0점**이다. 신고 총수는 개별 면 탐지율이나 점수가 아니다. 6대 경기의 BLUE 합계 평균은 158점, RED는 85.5점이며 두 경기 모두 BLUE가 승리했다. B-2 단독의 M1~M5 평균은 38.5점이다. 각 방식은 두 시드뿐이므로 일반적인 승률이나 평균 성능을 보장하지 않는다.

네 경기 모두 실행 오류 없이 완료했다. 첫 자가 대전 뒤 시드 1의 첫 시도는 여섯 로봇 중 두 대만 센서 준비를 마쳐 시작 전 제한 시간에 중단됐고 **채점에 포함하지 않았다**. 시드 1을 깨끗한 출력 폴더에서 재시도하여 완료했다. 사용자 요청이 2회로 축소된 뒤 세 번째 자가 대전은 시작하지 않았다. 영상 네 개의 사본은 WSL 원본과 SHA256이 일치한다. 전체 로봇별 보고와 채점 대조 JSON은 해당 회차 폴더에 보존했으며, WSL 원본은 `/home/jojo0429/maicon_candidate02_runs/`에 있다.

# 경기장 6.12×5.00m 좌표 통일 검증

2026-11-12. 1차 사전교육 PDF 23쪽 경기장 사양, 24쪽 인쇄 격자, 26쪽 전술 상황판을 확인했다. PDF는 약 612×500cm라고 쓰며 벽 안쪽/바깥쪽을 명시하지 않는다. 요청한 B-2 항법 시작점 (0.40,2.50)에 맞춰 이번 설정은 **주행 영역과 내벽 경계 6.12×5.00m**로 해석했다. 두께 0.06m 벽 포함 외곽은 6.24×5.12m다.

- Gazebo 중심 원점 유지. 항법 좌표는 (X+3.06, Y+2.50).
- B-2 world 출발 자세 (-2.66,0,0), 항법 (0.40,2.50,0).
- 원본 인쇄는 중앙 6.00×4.80m로 유지. 양옆 6cm·위아래 10cm는 가장자리 색을 연장한다. 20cm 격자, 거점 그림, 40cm 박스를 늘리지 않는다.
- BLUE/RED 각 3개 섹터, CM 및 거점 6개 구성을 유지한다. 박스/고정물/빔/거점 중심의 world 배치는 기존 layout과 인쇄 기준이다. 끝 섹터와 비채점 외곽 띠의 경계만 새 크기로 확장했다.
- team_node.py가 arena_spec.yaml을 전달한다. MAICON_ARENA_SPEC 또는 명령행 --arena-spec으로 현장 사양을 지정한다.
- 자가 대전은 실제 사용한 사양·배치 사본을 결과 폴더에 저장한다. 설치본과 소스의 사양/배치/UAV 보정 불일치는 실행 전 오류로 알린다.
- UAV 지도 표시와 위치 오차 평가도 저장된 크기/원점 변환을 사용한다. 이전 경기 결과 파일은 수정하지 않았다.

## 실제 확인

경기를 시작하지 않고 B-2 한 대를 대기 상태로 띄워 8초간 카메라, LiDAR, IMU, odom, 심판 상태를 수신했다. 실제 B-2 항법 위치는 (0.40000000003,2.49999999997)다. 450점 LiDAR가 최소거리로 붕괴하지 않았다.

실제 설치 SDF·메시 검사: 충돌체 28개, 시각 요소 57개, 텍스처 22개, 오류 0개. 바닥 표시는 여전히 하나의 시각 요소다.

실제 UAV 프레임으로 13개 점을 적합하고 별도 12개 점으로 검증했다. 검증 RMS 3.20mm, 최대 9.74mm. 알려진 카메라 위치·화각과 별도 비교한 최대 오차는 6.76mm다. 도면을 영상 위에 투영한 격자는 추가 측정 근거로 세지 않았다. 반복 무늬 오대응 실패 기록은 JSON으로 남겼다. 최종 특징점 유사도 기준은 0.33이며, 검증점을 오차 크기에 따라 제거하지 않았다.

관련 회귀 시험 **141개 통과**, 수정 Python 구문 확인, 실제 WSL 설치본과 수정 자산의 해시 일치. 5분 임무나 새 성능 점수는 이번 점검에서 산정하지 않았다.

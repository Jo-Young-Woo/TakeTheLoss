# B-2 단독 경기 — M5 점령으로 조기 종료

300초 실행을 요청했으나 경기 시작 후 247.164초에 B-2가 R-2 거점을 점령했다. 심판의 m5_capture 종료 조건으로 보고 단계에 진입했고, 기존 실행기가 Agent 종료와 함께 녹화를 닫아 영상은 249.233초다.

이 결과는 목표 거점 점령으로 종료된 경기 기록이지만, 요청한 300초 길이의 영상은 아니다. 300초 녹화 완료로 표시하지 않는다.

경기 종료와 녹화 종료 조건을 분리한 재실행 결과는 형제 폴더 gazebo_b2_uav_300s_complete_20261112에 저장한다. 거점 점령 후에는 최종 장부를 명시적으로 고정하고 실제 화면을 300초까지 녹화하며, 종료 후 새로운 임무나 식별을 수행했다고 간주하지 않는다.

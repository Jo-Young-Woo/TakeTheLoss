## 면 장부 결과

마지막 영상에서 박스 후보 20개, 방향별 면 후보 80개를 기록했다. 내부·벽 접근 불가 제외 28개, 나머지 52개다. 부분 노출 구간을 분리하여 저장한 선분은 58개다. 이 수치는 그림 종류나 M3 점수가 아니다.

UAV 기하는 RGB와 다점 격자 보정만 사용한다. LiDAR/오도메트리/월드 장애물 좌표는 이 독립 영상 장부의 입력이 아니다. 지상 상태는 원본 UAV 좌표·크기·방향이 일치하고 촬영 시각보다 이전의 자료일 때만 별도 연결한다. 마지막 스냅샷의 연결된 ground_state는 identified 11, empty 13, pending 27, viewed 1, excluded 28이다. 이 역시 공식 채점이나 정확도 검증 수치가 아니다.

노란 실선: 윗면 외곽(z=0.4m). 청록 점선: 같은 윤곽의 바닥 투영(z=0). 자홍 십자: UAV 수직 아래 지점. 원근 때문에 윗면과 바닥의 픽셀 위치가 다르다. 옆면 그림은 상공 윤곽만으로 식별 처리하지 않는다.

## 검증과 변경 범위

첫 관련 시험 묶음 64개, 추가 묶음 83개가 통과했다(7개 중복, 서로 다른 시험 총 140개). 원본 영상으로 재투영, 시각별 연속 확인, 내부 변 제외, LiDAR 지도 이동과 영상 기하 분리, LiDAR 전용 물체 제외, 미래/오래된 지상 상태 거절, 녹화 회귀를 포함한다.

기록 당시 코드 해시를 source_manifest.json에 보존했다. 실행 이후에는 패널 제목이 녹화 시간 줄에 가리지 않도록 y 위치만 조정했다. 보기용 영상은 저장 원본과 같은 프레임 장부로 다시 그렸으며 새로운 검출이나 관측을 만들어 넣지 않았다. 최초 합성 영상 uav_image_face_ledger.mp4도 보존했다.

현재는 축에 평행한 사각형 윗면을 가정하는 Gazebo 검출기다. UAV의 옆면 사진을 직접 분류하는 새 M3 모델이나 전체 가림 판정은 이번 구현 범위가 아니다. Agent의 임무 장부·경로계획은 계속 동작하며, 독립 영상 장부의 통계가 공식 점수나 임무 완료 판정을 덮어쓰지 않는다.

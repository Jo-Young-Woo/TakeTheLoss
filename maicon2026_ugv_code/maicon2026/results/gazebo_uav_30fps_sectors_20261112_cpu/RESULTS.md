# 실제 UAV 시점 녹화와 섹터별 박스 집계

2026-11-12. 현재 작업 코드로 3대3 / seed 0 / progress / 60초 시험을 다시 실행했다. 여섯 Agent가 모두 종료 코드 0으로 끝났으며 실행 오류는 없었다. 전체 300초 경기가 아닌 60초 재시험이다.

## 녹화

- 원본 영상: uav_native_rgb.mp4 (1280×720).
- 섹터 및 면 장부 표시 영상: uav_image_face_ledger.mp4 (1700×720).
- 실제 Gazebo 카메라는 고정 UAV와 같은 위치·회전·화각이다. World pose는 (0,0,2.5,0,π/2,π/2), 수평 화각은 130°이다.
- 임무 알고리즘의 UAV 입력은 1 Hz를 유지했다. 별도 녹화 카메라가 동일 시점에서 30 Hz로 렌더링한다. 장부 분석만 1초마다 갱신한다.
- 실제 수신 1,814프레임, 평균 29.809 fps. 30 fps 영상 60.867초, 출력 1,826프레임 모두 디코딩 성공.
- 시뮬레이션 시간에 맞추는 과정에서 이전 프레임 유지 44장(약 2.4%), 누락 안내 화면 0장이다. 콜백 대기열에서 30장이 탈락했고, 같은 출력 시간 칸에 들어온 32장은 별도로 출력하지 않았다. 생성 영상이나 움직임 보간은 사용하지 않았다.
- GPU 시험에서는 텍스처가 적용된 바닥·박스가 화면에서 사라졌다. 해당 실행은 중단하고 집계에서 제외했다. 이 정상 결과는 CPU 렌더링으로 다시 실행한 것이다. GPU 실패 기록은 형제 폴더 gazebo_uav_30fps_sectors_20261112에 보존했다.

## 영상에 표시된 B-2 관측 결과

UAV 영상의 박스 중심을 실측 섹터에 배정하고 박스 ID별로 중복을 제거했다. 식별 박스는 유효 옆면 하나 이상이 identified인 박스다. 모든 유효 면 확인은 제외 면을 뺀 모든 면이 identified 또는 empty인 상태다. U/H/미관측은 완료로 세지 않는다.

| 섹터 | UAV 박스 | B-2 식별 박스 | 모든 유효 면 확인 | 식별 면 |
|---|---:|---:|---:|---:|
| B-S1 | 3 | 0 | 0 | 0 |
| B-S2 | 2 | 2 | 0 | 2 |
| B-S3 | 3 | 1 | 1 | 2 |
| CM | 4 | 2 | 1 | 3 |
| R-S1 | 3 | 0 | 0 | 0 |
| R-S2 | 2 | 1 | 0 | 2 |
| R-S3 | 3 | 1 | 1 | 1 |
| 합계 | 20 | 7 | 3 | 10 |

섹터 밖 박스는 0개다. 마지막 영상 장부 시각은 시뮬레이션 61.116초, 연결한 B-2 관측 시각은 60.700초다. 영상 장부의 기하에는 LiDAR 좌표나 Gazebo 모델 정답 좌표를 사용하지 않았다.

이 수치는 여섯 로봇 합산 또는 공식 M3 점수가 아니다. identified에는 M2/M3 대상 식별이 포함될 수 있다. UAV 윗면으로 박스 위치를 확인한 것과 옆면 그림 식별을 구분해야 한다. B-2의 R-S1 식별은 0개이고 전체 M3 완료를 달성한 결과가 아니다.

## 검증 및 재현

카메라 설정·집계·보정 관련 시험 43개 통과. 실행 전후 소스와 설치 자원 424개 해시가 일치했다. 원본 영상과 장부 영상 모두 전체 프레임을 디코딩해 크기·프레임 수·실제 영상 변화를 확인했다.

- sector_box_report.json: 섹터별 상세 집계 및 박스별 면 상태.
- recording_validation.json: 영상 전체 재생 검증, 프레임 품질, 소스 해시 검증 결과.
- uav_camera_live_verified.json: 실행 중인 실제 월드에서 확인한 두 카메라의 pose·화각·해상도·주기.
- uav_recording_profile.yaml: 이번 실행에서 사용한 카메라 프로파일.
- selfplay_report.json: 6대 실행 종료 상태.

```bash
python3 scripts/run_wingbot_selfplay.py --output results/새_출력_폴더 --duration 60 --seed 0 --variant progress --scenario selfplay --record-view uav --uav-video-fps 30 --render-device cpu --ros-domain-id 180 --ready-timeout 180 --wall-timeout 1200
```

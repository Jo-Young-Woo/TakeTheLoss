# GPU 렌더링 검증 실패 — 채점·식별 집계에서 제외

2026-11-12. 실제 30 Hz UAV 시점 카메라로 3대3 실행을 시작했으나, D3D12 RTX 4060 Ti / Ogre2 화면에서 바닥 텍스처 및 텍스처 박스가 보이지 않는 현상을 원본 RGB로 확인했다. UAV 검출 박스는 0개였다.

해당 실행만 정상 중단했으며 selfplay_report.json의 completed는 false다. 이 영상·관측 결과를 정상 경기 또는 미션 성능으로 사용하지 않는다. 실제 로봇이 없는 박스를 통과한 것이 아니라 시각 렌더링이 누락된 상황이다.

정상 렌더링 재시험 결과는 형제 폴더 gazebo_uav_30fps_sectors_20261112_cpu에 별도로 저장한다. 두 시험은 서로 다른 ROS 도메인에서 순서대로 실행했다.

# 후보 02 실제 Gazebo 자가 대전 — 중도 종료, 합격 실패

300초 상한으로 시작했지만 약 168초에 R1의 미리보기 파일 저장이 실패하여 중단되었습니다. OneDrive/WSL 경로에서 `overlay.json.tmp`를 `overlay.json`으로 바꾸는 작업이 `PermissionError`로 거부되었습니다. 일시적인 파일 공유 잠금 가능성을 고려하여 재시도를 추가했지만 잠금을 잡은 프로세스까지 특정한 것은 아닙니다. R1 종료 코드는 1, 나머지 다섯 로봇은 정리·보고 후 0입니다. 이 실행을 완료 경기로 집계하지 않습니다.

영상 `wingbot_selfplay_third_person.mp4`는 **168.3초, 1280×720, 10fps, 1,683프레임**입니다. 누락·프레임 복제·큐 폐기 0이며 여섯 시점을 디코딩해 확인했습니다. 실제 여섯 로봇이 각자 RGB·LiDAR·odom·IMU와 UAV 영상을 사용했으며, 실제 모델 위치는 평가와 영상 식별에만 사용했습니다. `source_manifest.json`에 시작 전 소스·설치 파일 해시가 있습니다.

## 성능 결과

**파일 오류와 별개로 알고리즘 기준도 미달입니다.** 내부 감시 기준 12초 초과 정체는 6건, 독립 진척 감시에서는 5건입니다. 독립 정체 비율은 24.67%, 진동은 1건으로 각각 0건·5% 이하·0건 기준을 통과하지 못했습니다.

M3는 섹터·종류별 집계 비교이며 개별 면 탐지율이 아닙니다. B1은 과대 집계도 1개 있습니다. 210초에 도달하지 못했으므로 해당 시점의 전체 면 인식은 미검증입니다. 레이저 발사·M2 지정 표적 명중·UGV 피격·M5 거점 점령 이벤트는 모두 0입니다.

IMU 융합은 로봇별 3,233~3,249회 적용되었고 초기 바퀴 odom 복귀는 1~2회였습니다. B3의 기록 전체 위치 오차는 평균 0.151m, 최대 0.589m입니다. 동일한 첫 80초를 비교한 `b3_comparison_at80.json`에서는 후보 01 평균/최대 0.930/3.467m, 후보 02 0.245/0.589m이지만 이동 경로·이동량과 여러 알고리즘이 함께 달라졌으므로 IMU 단독 효과로 해석할 수 없습니다.

실제 여섯 로봇 부하에서 LiDAR 군집 처리 p95는 4.66~12.28ms였습니다. 위험 지도 worker의 요청부터 결과 발행까지 p95는 **227~310ms**, 계산만의 p95도 214~285ms로 100ms 목표를 넘었습니다. 이는 전체 카메라/ROS 수신부터 Agent 반응까지의 지연 측정은 아닙니다. 원본은 각 로봇의 `risk_worker_summary.json`입니다.
